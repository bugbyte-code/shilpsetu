# 🪔 ShilpSetu

### **Where Tradition Meets Technology.**

> **ShilpSetu** is an AI-powered digital marketplace designed to empower local artisans by helping them showcase, describe, price, and sell their traditional handicrafts in the digital world.

🌐 **Preserve the craft. Empower the artisan. Connect the world.**

---

## ✨ Why ShilpSetu?

India is home to thousands of traditional artisans whose skills and crafts have been passed down through generations.

But many artisans face challenges such as:

* 📱 Limited digital presence
* 🌍 Difficulty reaching customers beyond their local markets
* ✍️ Lack of professional product descriptions
* 💰 Difficulty estimating competitive prices
* 🛍️ Limited access to modern e-commerce platforms
* 🗣️ Language and technology barriers

**ShilpSetu bridges this gap.**

It combines **AI + e-commerce + cultural preservation** to create a digital platform built around the artisan rather than just the product.

---

# 🚀 What Makes ShilpSetu Different?

ShilpSetu isn't just another online marketplace.

### 🤖 AI-Powered Product Intelligence

Upload a picture of a handicraft and let AI help identify the product and generate:

* 🏷️ Product name
* 📝 Professional description
* 🧵 Craft/category information
* 💰 Suggested pricing
* 🎯 Product highlights

Instead of asking an artisan to become a digital marketer, **ShilpSetu brings the digital expertise to them.**

---

### 🎙️ Voice-First Experience

Artisans shouldn't need to be experts in typing or navigating complicated applications.

ShilpSetu is designed with a **voice-friendly experience**, making interaction more accessible and natural.

> **Speak → Understand → Create → Sell**

---

### 🧺 Digital Product Showcase

Artisans can create digital listings for their products and showcase their work to potential customers.

Each product can contain:

* Product image
* Product name
* Description
* Category
* Price
* Artisan information

---

### 🪷 Culture Meets Commerce

ShilpSetu doesn't treat handicrafts as ordinary products.

Every craft has a **story, culture and identity**.

The platform can help preserve information about:

> 🧑‍🎨 The Artisan
> ↓
> 🧵 The Craft
> ↓
> 🏛️ Its Cultural Heritage
> ↓
> ❤️ Its Story

This turns a simple product listing into a **digital cultural experience**.

# ⚡ Getting Started

## Prerequisites

Make sure you have:

* Flutter SDK
* Dart SDK
* PostgreSQL
* VS Code or Android Studio
* Git

---

## Installation

### 1. Clone the repository

```bash
git clone <YOUR_REPOSITORY_URL>
```

### 2. Enter the project

```bash
cd shilpsetu
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Configure your environment

Add the required API/database configuration according to your local setup.

> ⚠️ Never commit API keys or passwords to GitHub.

### 5. Run the application

```bash
flutter run
```

For web:

```bash
flutter run -d chrome
```

---

# 🔐 Security

API keys and sensitive credentials should be stored securely using environment configuration or a backend service.

**Never expose production API keys directly inside the Flutter client.**
